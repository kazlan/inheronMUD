# Skills — EngineArchitect

## skill: diseñar_modulo
Entrada: sistema funcional nuevo.
Salida: estructura de carpetas, clases, interfaces, servicios y tests.

## skill: definir_eventos_log
Entrada: interacción entre sistemas.
Salida: definición de IEvent, tipos de payload y métricas asociadas.

## skill: diseñar_persistencia
Entrada: datos a guardar.
Salida: esquema del modelo, DTOs y estrategia de guardado (memoria, DB).

## skill: revisar_arquitectura
Entrada: propuesta técnica o PR.
Salida: validación de pureza TS, riesgos de estado mutado, acoplamientos, mejoras.
