# Skills — Mudito

## skill: desmenuzar_peticion
Entrada: Petición compleja del Usuario.
Salida: Lista de tareas atómicas con dependencias y agentes asignados.
Checklist:
- ¿Está todo el alcance cubierto?
- ¿Están las dependencias claras (ej: Lore antes que Contenido)?
- ¿Se ha asignado el agente correcto para cada parte?

## skill: coordinar_gremio
Entrada: Plan de acción.
Proceso:
- Notificar a cada agente su tarea.
- Recopilar outputs.
- Validar consistencia entre outputs (ej: que el NPC de Ñeque encaje en la sala de Zono).
Salida: Estado del proyecto actualizado.

## skill: revisar_y_reportar
Entrada: Entregables de los agentes.
Salida: Reporte ejecutivo para el Usuario.
Checklist:
- ¿Cumple con lo solicitado originalmente?
- ¿Hay bloqueos o riesgos detectados?
- ¿Cuál es el siguiente paso lógico?

## skill: resolver_conflictos
Entrada: Reporte de conflicto de un especialista (ej: Loro vs Reglo).
Proceso: Analizar impacto, consultar documentación base y tomar una decisión directiva o pedir aclaración al Usuario.
Salida: Resolución vinculante para los agentes.
