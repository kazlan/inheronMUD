# InheronMUD Visual Assets Pack

Pack visual consolidado del proyecto **InheronMUD**.

## Contenido

### 01_promotional
Material promocional y key art:
- wallpaper desktop épico
- wallpapers móviles
- hero web horizontal
- key art vertical

### 02_backgrounds
Fondos funcionales para:
- login
- creación de personaje

### 03_ui_kit
Hojas de assets UI:
- botones y estados
- marcos y paneles
- navegación y HUD
- ornamentos y controles

### 04_branding
Branding principal:
- logo horizontal
- logo con emblema
- emblema brújula/cristal
- app icon / isotipo

### 05_world
- mapa artístico del mundo de Inheron

### 06_classes
Retratos de clases iniciales:
- warrior / knight
- mage / arcane
- ranger
- cleric
- rogue / assassin
- bard / scholar

### 07_icons
Set de iconografía funcional para app:
- vida
- maná
- energía
- oro
- XP
- quest
- combate
- chat
- mapa
- inventario
- ajustes
- comunidad
- facción
- lore

### 08_npcs
Set inicial de NPC importantes:
- rey / regente
- archimaga
- capitán de guardia
- mercader
- tabernera
- enemigo recurrente
- entidad oscura / villano

## Nota de producción
- Algunas imágenes contienen texto decorativo o elementos estilizados propios de generación visual.
- Para producción web conviene superponer textos definitivos con HTML/CSS/SVG cuando sea necesario.
- Los nombres de archivo están normalizados para facilitar integración en el proyecto.
